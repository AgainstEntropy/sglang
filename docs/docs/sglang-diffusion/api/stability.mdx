<Note>
**Proposal.** The SGLang Diffusion stability scope is an open decision for the
1.0 release. This page is the proposed answer. Until the maintainers accept it,
treat every tier below as proposed.
</Note>

## Tiers

- **Stable**: keeps working across all 1.x releases. It is not removed,
  renamed, or given a different meaning in a 1.x release, except through the
  [deprecation rule](#deprecation).
- **Experimental**: may change or be removed in any minor release (1.y). The
  release notes list every change. There is no deprecation window. An
  experimental interface can be promoted to stable in a minor release.

Anything not listed as stable on this page is experimental. This includes every
command-line flag and environment variable that is not named below.

Stability does not cover:

- **Output numerics.** Generated pixels, frames, and audio may change between
  minor releases. Output is bit-identical only within one version, on the same
  environment, with `--quality exact`.
- **Performance**, log messages, and error message text.
- **Model support.** Each model family follows its tier in the
  [model catalog](/docs/sglang-diffusion/compatibility_matrix). A stable route
  serving an experimental model family is experimental for that family.

## Compatibility rules

### Request and response fields

- The fields declared on the request and response models in
  `runtime/entrypoints/openai/protocol.py` are stable for the stable routes:
  `ImageGenerationsRequest`, `VideoGenerationsRequest`, `ImageResponse`,
  `VideoResponse`, and `VideoListResponse`. A declared field is not removed,
  renamed, or retyped, and its meaning does not change.
- Fields only grow. A 1.x release may add optional request fields and new
  response fields. Clients must ignore response fields they do not know.
- These declared fields are experimental, because they expose debugging,
  server paths, or experimental features: `diffusers_kwargs`,
  `enable_teacache`, `progressive_mode`, `progressive_levels`,
  `progressive_delta`, `profile`, `profile_all_stages`,
  `num_profiled_timesteps`, `perf_dump_path`, `output_path`,
  `upscaling_model_path`, `frame_interpolation_model_path`, and the response
  fields `file_path`, `file_paths`, `peak_memory_mb`, and `inference_time_s`.
- [Model-specific fields](/docs/sglang-diffusion/api/openai_api#model-specific-request-fields),
  which a model declares on its own `SamplingParams`, follow that model
  family's tier.
- Today, a field that the active model does not declare is dropped without an
  error. The proposal for 1.0 is to reject it with `400` and name the field.
- Rejecting an input that had no effect, or that selects an unsupported
  combination, is a bug fix, not a breaking change.

The same rules apply to the fields of the base `SamplingParams` class in the
Python API, and to the keys of a `--config` file.

### Deprecation

SGLang does not yet publish a compatibility policy for the LLM side. Until it
does, this rule is proposed for diffusion, and will be changed to match the LLM
policy once that page exists:

- A deprecated stable interface keeps working, and logs a warning when used,
  for at least one minor release before it is removed. An interface deprecated
  in 1.y is removed no earlier than 1.(y+1).
- A deprecated HTTP route is also marked `deprecated` in the OpenAPI schema.
- The release notes list each deprecation with its replacement, and each
  removal.
- Deprecations and removals happen only in minor releases.

`GET /models` is already marked deprecated in the OpenAPI schema, in favor of
`GET /v1/models`. It does not log a warning yet.

### Patch releases (1.0.x)

A patch release may contain:

- Bug fixes and security fixes, including fixes to experimental interfaces.
- Errors for inputs that are silently ignored today. Each one is listed in the
  release notes.
- Documentation and CI changes.
- Support for a new model, marked experimental, when it does not change shared
  code paths.

A patch release does not:

- Remove, rename, or deprecate any interface, stable or experimental.
- Change the default value of a stable flag or request field.
- Add a stable interface, or promote an experimental one.
- Raise a minimum dependency version, unless a security fix requires it.

## HTTP routes

These are all 40 routes that `create_app` in `runtime/entrypoints/http_server.py`
mounts, plus `/metrics`.

### Generation (OpenAI-compatible)

| Route | Tier | Reason |
| --- | --- | --- |
| `POST /v1/images/generations` | Stable | OpenAI Images API. Documented and tested in CI. |
| `POST /v1/images/edits` | Stable | OpenAI Images API. `mask` is rejected with `400`. |
| `GET /v1/images/{image_id}/content` | Stable | Download path for a generated image. |
| `POST /v1/videos` | Stable | OpenAI Videos API subset. Documented and tested in CI. |
| `GET /v1/videos` | Stable | Lists video jobs. |
| `GET /v1/videos/{video_id}` | Stable | Job status, polled by clients. |
| `DELETE /v1/videos/{video_id}` | Stable | Cancels the job and removes it. Returns `503` if cancellation cannot be delivered. |
| `GET /v1/videos/{video_id}/content` | Stable | Download path for a generated video. |
| `GET /v1/models` | Stable | OpenAI model discovery. |
| `GET /v1/models/{model}` | Stable | OpenAI model discovery. |

## Serving modes and integrations

| Interface | Tier | Reason |
| --- | --- | --- |
| Monolithic serving (default `--disagg-role monolithic`), including `--dp-size` | Stable | The default deployment, tested in CI. |
| [Disaggregated serving](/docs/sglang-diffusion/disaggregation): `--disagg-*` flags, worker URL flags, the `DiffusionServer` head, and the transfer between roles | Experimental | Role layout and flags are still changing. The head serves the same HTTP routes, with the tiers above. |
| `--backend diffusers` | Experimental | Runs upstream diffusers pipelines, which do not honor every SGLang flag. |
| Gradio web UI (`--webui`, `--webui-port`) and the `realtime_webui` demo | Experimental | Demos, not APIs. |
| [ComfyUI plugin](/docs/sglang-diffusion/comfyui) | Experimental | Integrated mode depends on ComfyUI internals. The plugin has no version pin and no end-to-end ComfyUI test. Server-mode nodes can be promoted once their inputs are tested. |

| External services: `--srt-encoder-*`, `--pe-server-url`, `--prompt-enhancer-config` | Experimental | Depend on a second server and on specific models. |

## Config file

| Interface | Tier | Reason |
| --- | --- | --- |
| `--config` file (JSON or YAML) | Stable | The format is stable. Each key has the tier of the flag of the same name. Unknown keys are dropped without an error today. |
| `--pipeline-config-path` JSON | Experimental | Its keys are internal `PipelineConfig` fields. |

## Environment variables

| Interface | Tier | Reason |
| --- | --- | --- |
| Cloud storage: `SGLANG_CLOUD_STORAGE_TYPE` and the `SGLANG_S3_*` variables | Stable | The only way to configure output upload. Tested in unit tests. |
| All other variables, including every `SGLANG_DIFFUSION_*` and `SGLANG_CACHE_DIT_*` variable | Experimental | Tuning and debugging switches. See [Environment variables](/docs/sglang-diffusion/environment_variables). |

## Python API

| Interface | Tier | Reason |
| --- | --- | --- |
| `from sglang.multimodal_gen import DiffGenerator, SamplingParams` | Stable | The offline entry point. |
| `DiffGenerator.from_pretrained`, `from_server_args`, `generate`, `generate_action`, `set_lora`, `merge_lora_weights`, `unmerge_lora_weights`, `list_loras`, `shutdown` | Stable | The 9 public members. Keyword arguments to `from_pretrained` have the tier of the matching flag. |
| `DiffusionRuntimeError` (`sglang.multimodal_gen.runtime.utils.device_errors`) | Stable | Raised on a device failure or a dead worker. After it, every call raises it again; create a new generator. |
| Base `SamplingParams` fields | Stable | Same rules as [request fields](#request-and-response-fields). |
| Model-specific `SamplingParams` subclasses | Experimental | Follow the model family's tier. |
| `PipelineConfig` and its subclasses | Experimental | Internal configuration. Exported for advanced use only. |
| Everything else under `sglang.multimodal_gen` | Experimental | Internal. |
